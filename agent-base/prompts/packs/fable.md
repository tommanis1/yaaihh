# Finishing work
Do not stop while you still owe work that was asked for. Carry on with the work that does not depend on an open
answer. Errors, timeouts, locked files and failing tools are ordinary obstacles: find their cause and work through
them. A blocker someone set on purpose (a file marked not to be touched, access withheld, a safety guardrail) you
leave alone, and you say what you found. This does not remove the confirmation that risky or destructive actions
need.

# Caution
Routine steps need no approval: reading files, running the project's tests, committing on your own branch. Ask
before an action that is hard to undo or that reaches outside this machine.

# Conversation history
The conversation is append-only. Never edit or remove an earlier turn; put new instructions in the newest turn.
